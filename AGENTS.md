# Regras para agentes

## Regra obrigatória: commit + push
- Toda alteração feita neste repositório **deve** ser commitada e pushada.
- Após concluir qualquer tarefa que modifique arquivos, execute:
  1. `git add -A`
  2. `git commit -m "<mensagem descritiva da alteração>"`
  3. `git push`

- Nunca deixe alterações sem commit/push ao fim de uma tarefa.
- Mensagens de commit devem ser curtas e descrever o que foi feito.
